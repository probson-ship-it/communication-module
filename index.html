CSM FAQ - Communications Module

The Communications Module keeps questions and clarifications inside The Compliance Engine so AHJs and service providers can stay aligned, reduce email noise, and close the gap that often leads to lack of compliance.

What is the BRYCER Communications Module?

The Communications Module is an embedded messaging tool inside TCE. It allows AHJs and service providers to exchange clarification questions inside the exact report or workflow where that information belongs.

It is not designed as real time chat. Instead, it is a structured and traceable way to cut noise, reduce misrouted emails, and keep every question connected to the specific inspection, deficiency, or property that needs action.

Primary purpose: reduce confusion, close communication gaps and remove barriers that prevent jurisdictions from reaching full fire and life safety compliance.
Product behavior

How the feature works

1. Where will this feature be found? +

The messaging feature appears inside the specific report or workflow where the conversation was started. It will not appear globally across TCE. This keeps every thread tied directly to the work instead of spread across inboxes.

2. How do users find a conversation, and is it an open chat box? +

Users simply return to the same report where the message was created. The full thread appears there.

There is no floating chat window and no platform wide inbox. Conversations stay anchored to the specific record that needs attention.

3. Can users attach files or photos? +

No, not at this time.

4. Is there historical message history? +

Yes. From the moment the first message is sent, the full conversation is saved so both sides can revisit previous communication tied to that record.

5. Are there online indicators or read receipts? +

No. The feature does not include online or offline status, typing indicators, or read receipts.

This keeps expectations realistic and reinforces that the feature is for organized follow up, not instant chat.

6. Can users export message history? +

No, not at this time.

Visibility and routing

Who can see what

7. Who sees the messages? +

Visibility is based on who starts the conversation:

If a service provider starts the message:

  • Everyone in the AHJ department can see the message.
  • Only the specific service provider user who started it can see the message on the provider side.

If an AHJ starts the message:

  • Only the AHJ user who sent it sees the message on the AHJ side.
  • Everyone at the service provider company with appropriate access can see the message on their side.

This structure routes communication to the right people without overwhelming entire teams.

Notifications and control

Notifications, muting and hub

8. How do notifications and muting work? +

Email notifications:

Message alerts are included in existing daily or weekly digest emails. Users cannot turn message alerts on or off separately. To stop message alerts, they would need to turn off the digest.

Muting or disabling messaging:

Messaging can be turned off for individual users or for departments and organizations. When messaging is turned off, users lose both the ability to send new messages and to receive new ones.

9. Will there be a hub where users can view all their messages? +

Yes. A centralized Conversation Hub will be available so users can see an organized list of the conversations they have started across TCE.

The hub is a structured summary view, not a real time inbox. It is designed to help users return to ongoing clarification threads without digging through individual reports or external email.

Quick reference

When you talk about the Communications Module, connect it back to our core problem statement: many jurisdictions struggle with lack of compliance because communication is scattered, incomplete or out of context.

  • It keeps questions and answers inside TCE, right where work happens.
  • It reduces email noise and misrouted requests.
  • It helps AHJs and service providers close the gap between reports and action.

When in doubt, emphasize:

  • Structured messaging, not chat.
  • Context: communication tied to a specific record.
  • Fewer barriers for jurisdictions trying to reach full compliance.
  • Control: AHJs still maintain authority and oversight.
